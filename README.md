# Upong

> [!Note]
> There are no levels or any multiplayer mode yet on the initial versions
> But an enemy AI, win/loss mechanism and smooth experience is available

Also, win/loss happens at max score only and the ball keeps bouncing without
resetting until either one reaches max score

To install it; run `cargo install upong` and then `upong`.
Then hit `Enter` and start the gameplay with your enemy AI.
Enjoy!
