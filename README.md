# Upong

> [!Note]
> There are no any multiplayer mode yet on the initial versions
> But an enemy AI, win/loss mechanism, difficulty levels are available

Also, win/loss happens at max score only and the ball keeps bouncing without
resetting until either one reaches max score

Checkout [Changelog](./CHANGELOG.md) for more details

To install it; run `cargo install upong` and then `upong`.
Then click on `Play`, select difficulty level and start the gameplay with your enemy AI.
Enjoy!
